# DevOps Implementation Package

This package contains the Student Complaint Management System source and the supplied project documentation.

DevOps tools used for the project:
- Git — version control
- GitHub Actions — Continuous Integration
- Jira — Agile project management

Note: Git repository history, GitHub Actions run history, and Jira project/issue data live in their respective online accounts and are not embedded in this ZIP. They should be shown using screenshots/links when documenting the DevOps implementation.
